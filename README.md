# Telegram Secretary Bot

Этот проект представляет собой Telegram-бота-секретаря для факультета.  
Ниже приведена подробная инструкция по установке и запуску проекта.

---

## 1. Клонирование проекта

1. Создайте папку на компьютере, куда хотите установить бота.  
   Убедитесь, что Git установлен.
2. Откройте терминал (Git Bash, PowerShell или аналогичный) в этой папке и выполните:
git clone https://github.com/vintage1500/secretary_faculty.git

3. После завершения клонирования откройте репозиторий в любом удобном редакторе кода (например, VS Code).

---

## 2. Настройка базы данных PostgreSQL

1. Установите PostgreSQL (вместе с pgAdmin).
2. Подключитесь к серверу через pgAdmin, используя свой пароль.  
Если забыли пароль, его можно сбросить или использовать Docker.
3. Создайте новую базу данных для проекта.
4. В файле `config.py` укажите свои параметры подключения:

DB_NAME = "your_database_name"
DB_USER = "your_username"
DB_PASSWORD = "your_password"
DB_HOST = "localhost"
DB_PORT = "5432"

3. Установка зависимостей

Перед запуском рекомендуется использовать виртуальное окружение.
Создание виртуального окружения:
python -m venv venv

Активация виртуального окружения:
source venv/bin/activate     # для Linux / MacOS
venv\Scripts\activate        # для Windows

Установка зависимостей:
pip install -r requirements.txt

4. Создание Telegram-бота

В Telegram найдите бота @BotFather.
Создайте нового бота с помощью команды /newbot и получите токен.

В корне проекта (на уровне config.py) создайте файл .env и добавьте туда переменные окружения.
Пример .env файла:
TOKEN=1234567890:ABCDefghijklmnopqrstuvwxyz

Не добавляйте .env в Git — внесите его в .gitignore (по дефолту вынесен).

5. Запуск бота
После настройки всех зависимостей и конфигурации запустите бота:
python bot.py

6. Проверка работы
В Telegram найдите своего созданного бота.
Отправьте команду /start.
Если появилось приветственное меню, значит бот работает корректно.

7. Работа с базой данных
Некоторые кнопки (например, FAQ) могут не работать, если база данных пустая.

Чтобы бот функционировал полностью:
- Ознакомьтесь с кодом;
- Заполните базу тестовыми данными;
- Проверьте работу всех функций.

8. Полезные советы
Проверяйте корректность данных в .env и config.py.
Убедитесь, что PostgreSQL запущен перед запуском бота.
Для тестов можно использовать Docker-контейнер с PostgreSQL.
При необходимости настройте логирование для удобства отладки.

9. Готово
Если всё выполнено корректно, бот успешно запущен и готов к работе.
